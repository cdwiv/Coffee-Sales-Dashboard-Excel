**Coffee Sales Analysis Dashboard**

A comprehensive Excel-based dashboard designed to track and analyze coffee sales performance across multiple regions, roast types, and customer segments from 2019 to 2022.

**Dashboard Overview**

This project transforms raw sales data into actionable insights, allowing stakeholders to monitor revenue trends and identify top-performing products and customers.

**Key Visuals:**

1. Total Sales Overtime: A multi-series line chart comparing revenue across four coffee bean types (Arabica, Excelsa, Liberica, and Robusta).
2. Sales by Country: A bar chart showing market dominance, with the United States leading significantly.
3. Top 5 Customers: A ranking of individual customers by total spend, led by Allis Wilmore.
4. Interactive Slicers: Dynamic filtering by Roast Type (Dark, Light, Medium), Size, and Loyalty Card status.

**Features & Functionality**

1. Dynamic Timeline: Allows users to drill down into specific months or years (2019–2022) to see seasonal trends.
2. Cross-Filtering: Selecting a roast type or size automatically updates all charts globally.
3. Data Cleaning: Built using Excel functions (XLOOKUP, INDEX/MATCH) and Pivot Tables to ensure data integrity.

**Project Structure**

Coffee_Sales_Data.xlsx: The main workbook containing raw data.

Coffee_Sales.xlsb: The final workbook containing edited data, processing sheets, and the final dashboard.

coffee_sales_dashboard: Contains screenshots of the dashboard for quick preview.
